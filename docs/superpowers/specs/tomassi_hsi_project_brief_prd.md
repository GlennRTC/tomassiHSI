# Project Brief: Tomassi HSI (Healthcare Systems Integrations)

## 1. Project Overview
**Brand Name:** Tomassi HSI
**Principal Consultant:** Glenn Tomassi
**Industry:** Healthcare IT / Interoperability Consultancy
**Core Value Proposition:** Designing, deploying, and maintaining high-fidelity clinical data interfaces and health software solutions with engineering-grade precision.

## 2. Brand Identity & Visual Language (Carbon Light)
The project utilizes the **Carbon Light** design system, characterized by industrial rigor and clinical clarity.

*   **Color Palette:**
    *   Primary: Signal Orange (`#FF6B00`) for CTAs and critical data status.
    *   Background: Pure White (`#FFFFFF`) with a technical grid overlay.
    *   Typography: JetBrains Mono for data-dense sections (Technical Logs, Protocol Tags) and high-legibility sans-serif for body copy.
*   **Design Principles:**
    *   **Blueprint Aesthetic:** Layouts based on rigid technical grids.
    *   **Functionalism:** Minimalist, declarative copy with no "sales-adjacent" emotional language.
    *   **High Information Density:** Clear hierarchy for complex technical specifications.

## 3. Core Capabilities & Services
Tomassi HSI specializes in resolving data silo issues through three primary technical vectors:

### A. Technical Implementation
*   **Clinical System Integration:** HL7v2 and FHIR interfaces between LIS, HIS, and CDS.
*   **Analyzer/Hardware Connection:** Bidirectional ASTM interfaces and middleware configuration.
*   **Custom Health Solutions:** API-first development, FHIR Gateways, and automated clinical reporting.

### B. Strategic Consultancy
*   Interoperability diagnostics and technical roadmaps.
*   Vendor review and technical RFP accompaniment (LIS/HIS selection).
*   Internal team mentorship for integration projects.

## 4. Methodology (Project Lifecycle)
Projects follow a 6-phase technical workflow:
1.  **Iniciación (Initiation):** Audit of existing HL7/FHIR protocols and data flow mapping.
2.  **Planificación (Planning):** Scope definition and interface milestone setting.
3.  **Diseño (Design):** Routing architecture and message transformation rules.
4.  **Ejecución (Execution):** Channel configuration in integration engines (e.g., Mirth Connect).
5.  **Pruebas (Testing):** Simulation of critical scenarios and schema validation.
6.  **Cierre (Closure):** Production monitoring and L2/L3 support handover.

## 5. Technical Stack & Standards
*   **Protocols:** HL7v2, HL7v3, FHIR R4, ASTM, CDS Hooks, DICOM.
*   **Tools:** Mirth Connect (NextGen Connect), Rhapsody, Postgre SQL, MySQL.
*   **Formats:** JSON, XML, SOAP, REST, OpenAPI Specs.

## 6. Target Audience & Market
*   Clinical Laboratories (Venezuela, LATAM, Canada).
*   Hospitals and Integrated Health Networks.
*   HealthTech Startups requiring legacy system integration.

## 7. Key Project Artifacts
*   **Technical Log:** A verified record of recent implementations (e.g., LIS/HIS Sepsis Correlation Motor).
*   **Interoperability Blueprint:** Visual mapping of technical reach and data modeling capabilities.
*   **Interactive Methodology Flowchart:** A step-by-step technical guide for stakeholders.
